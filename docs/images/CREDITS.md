# Where the screenshots came from

The screenshots in the README are of a real DeskVNC build, connected over real
VNC to demo servers running on `127.0.0.1`. They are there to show the client,
so treat everything inside a remote desktop in them as illustration rather than
as a claim about any particular machine. No real host, address, credential or
network of the author's appears in any of them.

## The rest

Every other thumbnail in the library grid, including the Windows ones, is a
drawing made for this repository rather than a capture of the software it
depicts. There is no freely licensed Windows desktop screenshot to use:
Microsoft's interface is theirs, and the copies circulating on the web belong
to whoever captured them. So those tiles stand in for what a real session looks
like, and nothing more. A genuine capture is welcome if you have one to give.

The host names, addresses, groups and tags in the library are invented. The
addresses that are not `127.0.0.1` do not resolve anywhere.
